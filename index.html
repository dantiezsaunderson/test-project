    How to use the bot (quick guide)

    1. Start a workspace: log into openclaw.ai and create a Clawd bot workspace.
    2. Define your thesis: write short prompts for each market (timeframe, risk level, and goals).
    3. Connect data: add price feeds, news, social, on-chain, or marketplace comps.
    4. Build watchlists: set tickers, pairs, or collectible sets with priority tags.
    5. Set alerts: define thresholds for volatility, spread widening, or sentiment spikes.
    6. Configure guardrails: add max drawdown limits, position sizing rules, and a kill switch.
    7. Paper test: run the bot in simulation for at least two weeks to validate signals.
    8. Review weekly: track hit rates, false positives, and adjust thresholds.
    9. Go live carefully: scale slowly once the bot performs reliably.

    Keep humans in the loop. Use Clawd bot for research and alerts, then make final decisions.
