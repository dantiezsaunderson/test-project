# KMS Records Social Media Asset Plan

This repository contains a single-page guide that outlines how to research, acquire,
and produce high-quality assets for KMS Records social media content. It includes:

- A series concept for legacy-driven content
- Asset inventory checklists and rights workflow
- Production and publishing guidelines
- HQ post specifications for feed, reels, and stories
- A research dossier (timeline, quotes, artist database, release cards)
- Content pillar drafts (reels, static posts, carousels, captions)

## Project Structure
- index.html - Main HTML document
- styles.css - Styling and layout
- script.js - Timestamp utility
- KMS_MASTER_TIMELINE.md - Verified timeline scaffold
- KMS_KEY_QUOTES.txt - Quoted source bank
- KMS_ARTIST_DATABASE.csv - Artist and release map
- KMS_RELEASE_CARDS.json - Automation-ready release cards
- reels/ - Reel scripts
- static/ - Static post specs
- carousels/ - Carousel timelines
- captions/ - Caption bank
- templates/ - Template specs
- calendar/ - 30-day calendar + automation notes
- assets/ - Logos and social SVG templates
- automation/ - Posting agent scaffold

## Usage
Open `index.html` in a browser to view the plan. Update the content as new assets
are collected and new campaigns are planned.
