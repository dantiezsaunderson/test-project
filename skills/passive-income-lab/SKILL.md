# Passive Income Lab

Use this skill to propose, score, and validate **legitimate** passive income
opportunities and small business models. Focus on realistic, ethical, and
repeatable ideas.

## Workflow

1. Ask for constraints:
   - Time per week
   - Starting capital (if any)
   - Existing skills / tools
   - Region or target audience
2. Generate 10 opportunities, each with:
   - Problem solved
   - Target customer
   - Monetization path
   - Time to first revenue
3. Score each idea on:
   - Demand (1-5)
   - Margin (1-5)
   - Moat (1-5)
   - Execution difficulty (1-5, lower is better)
4. Recommend top 3 with:
   - 30/60/90-day execution plan
   - MVP checklist
   - First $100 test

## Safety

Avoid illegal, exploitative, or misleading activities. Keep it factual and
research-focused, not financial advice.
