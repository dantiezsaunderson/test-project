KMS Template Specs (Production Notes)
=====================================
Purpose: Build reusable templates in Figma/Canva and export PNGs.

Brand Defaults
--------------
Palette:
- Black: #0B0C10
- Charcoal: #151824
- Grit Gray: #2A2F3A
- Accent Gold: #F2C14E
- Offwhite: #F4F6FB

Type:
- Headline: Space Grotesk (or Inter if unavailable)
- Body: Inter
- Caption/Meta: IBM Plex Mono (or Inter Mono)

Grid + Spacing:
- 12-column grid, 24px gutters, 96px outer margin (desktop)
- 48px outer margin (1080 formats)
- Safe text zone: 80px inset on all sides

Templates
---------
1) Instagram Reel Cover (1080x1920)
   - Top-left: KMS logo
   - Center: Title (max 5 words)
   - Bottom: Date + catalog number (if applicable)

2) Quote Card (1080x1080)
   - Full-bleed black or archival texture
   - Quote in headline type, 3-5 lines
   - Credit line in mono at bottom-right

3) Artist Spotlight (1080x1080) — PSD + PNG
   - Left: portrait crop (60%)
   - Right: name + release highlight
   - Footer: catalog number + year

4) Timeline Carousel (1080x1350)
   - Slide 1: Title + year range
   - Slides 2-5: 1 key fact per slide
   - Slide 6: “KMS Records” lockup + CTA

5) Vinyl Post (1080x1080)
   - Sleeve centered, slight drop shadow
   - Small label macro in corner
   - Caption line in mono

Export Requirements
-------------------
- PNG for graphics, JPG for photos
- sRGB color profile
- File naming: post-title-YYYY-MM-DD.png

Figma + Canva Notes
-------------------
- Build master components for typography + grids
- Lock logo position and safe margins
- Duplicate templates per post ID and update content
